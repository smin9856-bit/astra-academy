## 파일

GitHub의 `index.html`은 이미지·코드를 포함한 단일 실행 파일입니다. 다운로드해 직접 열 수도 있습니다. 작업 폴더에서는 `play.html`이 같은 단일 파일 버전이며, `index.html`은 분리된 모듈을 사용합니다.

`source.zip`에는 분리된 게임 코드, 캐릭터 일러스트, 배경, 스프라이트 시트, 모션 도감이 들어 있습니다. 압축을 풀고 정적 웹 서버에서 `index.html` 또는 `atelier.html`을 열면 됩니다.

아트는 사용자 레퍼런스 기반 이미지 생성으로 제작했습니다. 캐릭터별 여섯 개 키포즈를 분리하고, 동일 배율·발 기준점을 적용해 7가지 상태의 모션 시트로 조립했습니다. 전체 프레임을 수작업으로 그린 방식은 아닙니다. 모든 영웅은 성인 캐릭터입니다.
