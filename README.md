## 파일

GitHub의 `index.html`은 이미지·코드를 포함한 단일 실행 파일입니다. 다운로드해 직접 열 수도 있습니다. 작업 폴더에서는 `play.html`이 같은 단일 파일 버전이며, `index.html`은 분리된 모듈을 사용합니다.

`source.zip`에는 분리된 게임 코드, 캐릭터 일러스트, 배경, 스프라이트 시트, 모션 도감이 들어 있습니다. 압축을 풀고 정적 웹 서버에서 `index.html` 또는 `atelier.html`을 열면 됩니다.

아트는 사용자 레퍼런스 기반 이미지 생성으로 제작했습니다. 캐릭터별 여섯 개 키포즈를 분리하고, 동일 배율·발 기준점을 적용해 7가지 상태의 모션 시트로 조립했습니다. 전체 프레임을 수작업으로 그린 방식은 아닙니다. 모든 영웅은 성인 캐릭터입니다.

## 시즌·컵 결과 보드

- 순위와 관계없이 리그 최종전 종료 시 결과 보드 자동 표시. 컵 탈락 직후 우리 팀 성적을 안내하고, 남은 결승 종료 후 우승 학교를 포함한 최종 보드를 다시 표시합니다.
- 최종 순위표·전체 컵 대진표, 승무패·승률·처치/피처치·누적 피해/회복·평균 경기 시간, 선수별 누적 통계, 경기 결과와 지급 보상 내역
- 리그/컵 우승 MVP: 해당 대회 절반 이상 출전한 우리 팀 선수 중 평균 평점 1위. 동률이면 경기 MVP 횟수, 출전 수, 처치 수 순으로 선정합니다.
- 결과 → 도트 우승 세리머니 연결. 기록실의 ‘대회 결과’에서 다시 볼 수 있으며 보상은 중복 지급되지 않습니다.
- 순위·통계·보상·MVP는 종료 시점의 기록으로 보관합니다. 기존 저장의 남아 있는 결과는 복원하고, 상세 기록이 부족하면 집계 범위를 표시합니다.
