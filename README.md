# ASTRA ACADEMY · TACTICS

판타지 아카데미의 코치가 되어 5명의 팀을 훈련하고 전술을 구성하는 한국어 전투 매니지먼트 게임입니다.

## 바로 플레이

**https://smin9856-bit.github.io/astra-academy/**

설치 없이 PC·모바일 브라우저로 플레이합니다. 첫 로딩에는 이미지와 애니메이션을 내려받습니다.

- 5대5 자동 전투, 진형·타깃·템포 설정, 전투 통계
- 전술 연구실: 기본 진형 6종 선택 또는 영웅을 드래그해 원하는 위치에 직접 배치
- 학생 모집, 훈련, 성장, 6경기 시즌 리그
- 오리지널 영웅 12명 + SSR 크리스티아누 호날두
- 호날두는 무료 합류: 선수단 관리 → 호날두 → 스타팅 멤버로 편성하기
- GOAT 멘탈 / 호날두 킥 / Siuuu!!, 전용 모션과 전투 효과

진행 상황은 각자의 브라우저에 자동 저장됩니다. 로컬 실행과 온라인 주소의 저장은 별개입니다. 현재는 각자 플레이하는 싱글 플레이 게임이며 실시간 PvP는 없습니다. 실제 결제 기능은 없습니다.

## 파일

`index.html`은 이미지·코드가 포함된 단일 실행 파일입니다. 다운로드해서 브라우저로 직접 열 수도 있습니다.

`source.zip`에는 분리된 게임 코드, 캐릭터 일러스트, 배경, 스프라이트 시트, 모션 도감이 들어 있습니다. 압축을 풀고 정적 웹 서버에서 `index.html` 또는 `atelier.html`을 열면 됩니다.

아트는 사용자 레퍼런스 기반 이미지 생성과 프레임 변형 애니메이션을 함께 사용했습니다. 모든 영웅은 성인 캐릭터입니다.
